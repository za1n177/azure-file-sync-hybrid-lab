# Issue: File Sync Conflicts

## Symptoms
- Duplicate files
- Conflict files created
- Unexpected overwrites

## Root Cause
- Same file modified in two locations
- Simultaneous edits

## Resolution
- Review conflict files
- Decide authoritative copy
- Educate users on sync behavior

## Exam Tip
Azure File Sync resolves conflicts by preserving both versions.
