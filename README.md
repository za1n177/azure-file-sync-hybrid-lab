# Azure File Sync – Hybrid Lab (AZ-104)

## Overview
This hands-on lab demonstrates a real-world **Azure File Sync hybrid deployment**, integrating an on-premises Windows file server with Azure Files.

The lab covers:
- Azure File Sync architecture and constraints
- Sync group design
- Cloud endpoint and server endpoint configuration
- File synchronization validation
- Common troubleshooting scenarios
- AZ-104 exam-relevant concepts tested in real environments

All steps are performed using **real Azure resources** and validated through the Azure Portal, PowerShell, and file-level testing.
