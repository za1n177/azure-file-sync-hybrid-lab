# Azure File Sync – Core Concepts (AZ-104)

## Key Components
- Storage Sync Service
- Sync Group
- Cloud Endpoint
- Server Endpoint
- Azure File Share

## Definitions
- Cloud endpoint = Azure File Share
- Server endpoint = Local NTFS path on Windows Server
- Sync group = Logical container linking endpoints

## Exam Tip
Azure File Sync is managed by the **Storage Sync Service**, NOT the storage account.
