# Sync Groups & Endpoints

## Rules You MUST Remember
- One sync group = ONE cloud endpoint
- One sync group = MANY server endpoints
- A server endpoint maps to a local folder (NTFS path)

## Exam Trap
❌ Multiple Azure file shares in one sync group  
✅ Only one cloud endpoint allowed

## Real-world Scenario
Used to sync multiple branch servers to a single Azure File Share.
