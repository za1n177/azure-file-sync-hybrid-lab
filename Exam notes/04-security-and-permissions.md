# Security & Permissions

## NTFS Permissions
- Preserved by Azure File Sync
- Must be correct on server before syncing

## Identity Options
- Access keys (default)
- Identity-based access (Entra ID / AD DS integration)

## Exam Trap
Azure File Sync does NOT manage permissions — NTFS does.
